# `swap`

<!--dt-desc-start-->
Gives the status of what MQ2BardSwap is doing, and setting information

## Members

///

///

/// member | bool MeleeSwap
returns true if meleeswap is enabled
///

/// member | int Delay
Returns the delay of melee swap
